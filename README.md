# 🌶️ SPyCe Compiler

SPyCe, short for Simple Python and C Environment, is a beginner-friendly programming language that combines Python’s readability with C’s explicit structure to teach core programming concepts so learners see both how to write readable code and how types and declarations work. “SPyCe” reflects its goal to make learning programming approachable and enjoyable, like a gentle seasoning.

## Try out SPyCe

To run this project:

**1. Make sure you have the following:**
- Python (version 3.11 and above along with pip)
- node (version 24.4 and above along with npm)

You can check if you have these by running this in your command prompt:
```
  python --version
  node --version
```
Download the following if they are not found in your device
- Python - https://www.python.org/
- Node - https://nodejs.org/en

**2. Download the files or clone the repository**
- Download the ZIP or
- Run this in your terminal in a new directory 
```
  git clone https://github.com/JiArcangel0916/spyce.git
```

**3. Once opened in your code editor, install the dependencies for the frontend**
```
    npm install
```

**4. Create a virtual environment and activate it**
```
    python -m venv myEnv
    myEnv/Scripts/activate
```

you should see something like this in your terminal after:
```
  (myEnv) PS C:\Users\...
```

**5. Install the dependencies for the backend**
```
    pip install -r requirements.txt
```

**6. After everything is set, run the backend first with:**
```
  python run.py
```

**7. In a new terminal or a split terminal, run the frontend with:**
```
  npm start
```
The compiler will automatically open your browser.


## What SPyCe Offers

As a beginner-friendly programming language, SPyCe offers the necessary tools to perform a variety of programs for users to learn programming basics such as:
- Statically-typed Mutable and Immutable Variables (int, float, string, bool)
- Functions
- Mix Data Structure (similar to lists in Python)
- Built-in Functions (Input/Output, Typecasting, and other Utility Functions)
- String and Mix Indexing
- Control Structures (Conditionals and Iteration)
